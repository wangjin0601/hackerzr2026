## 5. 成本测算方法

```
单次陪练模型成本 = Σ(各次调用输入 token × 输入单价 + 输出 token × 输出单价)
单次语音成本     = ASR 时长 × 单价 + TTS 字符数 × 单价
单次总成本       = 模型成本 + 语音成本

人工带教成本     = 带教时长（小时）× 人力成本（元/小时）
                 示例：0.5 小时 × 50 元/小时 = 25 元/次（人力成本以公司实际数据为准）

年度节省（估算） = 年练习次数 × (人工带教成本 − 单次总成本)
```

实际数据由模型封装层的 token 统计得出，试点结束后填入汇报材料。
