# 02 产品方案

## 1. 用户角色

| 角色 | 诉求 | 使用方式 |
|---|---|---|
| 一线员工（销售/客服/服务） | 随时练话术，知道自己哪里不足 | 企业微信 H5 对练 |
| 新人 | 快速上手、敢开口 | 低难度场景 + 求助提示 |
| 主管/培训负责人 | 了解团队练习情况与共性短板 | 管理看板（复赛阶段） |
| 业务专家/销冠 | 沉淀话术、定义评分标准 | 维护场景 YAML 与话术库 |

## 2. 核心功能

### 2.1 MVP（初赛必须）

1. **场景选择**：展示场景卡片（名称、难度、预计时长、客户性格简介）。
2. **对练对话**：
   - AI 扮演客户，按画像和隐藏状态做出反应。
   - 支持文字输入；支持"按住说话"语音输入，客户回复可语音播放。
   - 达成结束条件（成交 / 客户挂断 / 轮数上限 / 主动结束）后进入报告。
3. **求助提示**：员工卡壳时点"求助"，AI 教练给出简短提示（计入报告，提示次数影响得分）。
4. **评分报告**：
   - 总分 + 各维度得分（雷达图）。
   - 逐轮点评：亮点 / 问题 / 推荐话术。
   - 客户"内心独白"复盘：展示客户每轮信任值变化与真实想法（教学价值高，视频效果好）。
5. **历史记录**：查看自己的练习记录与分数趋势。

### 2.2 复赛扩展（可选）

- 闯关与排行榜（个人/部门）
- 管理者看板（练习人数、平均分、薄弱维度 Top3）
- 每日一练：企业微信消息推送 3 分钟小场景
- 新品资料一键生成练习场景
- 实时语音通话式陪练

## 3. 用户流程

```
企业微信工作台 → 点击"AI客户陪练"（OAuth 免登，识别工号/部门）
   → 场景列表（按部门推荐）
   → 场景说明页（客户背景、本次目标）
   → 对练页（语音/文字，多轮）
        ├─ 求助 → 教练提示
        └─ 结束
   → 评分报告页（总分、雷达图、逐轮点评、客户内心独白）
   → 再练一次 / 换场景 / 查看历史
```

## 4. MVP 场景清单（首批 3 个）

| 编号 | 场景 | 适用岗位 | 核心考察点 |
|---|---|---|---|
| S01 | 嫌贵比价的客户 | 销售 | 价值塑造、异议处理 |
| S02 | 犹豫拖延的客户（"我再考虑考虑"） | 销售 | 需求挖掘、促成 |
| S03 | 情绪激动的投诉客户 | 客服/服务 | 情绪安抚、问题解决、合规表达 |

具体业务内容（产品、价格区间、常见异议）待与业务部门确认，见 `07-open-questions.md`。

## 5. 体验原则

- 一次练习控制在 3~8 分钟，碎片时间可完成。
- 移动端优先，按钮大、字少。
- 报告先给结论（总分与一句话评价），再给细节。
- 鼓励为主：每份报告至少给出 1 个亮点。
